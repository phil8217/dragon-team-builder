# 龍魂旅人網頁版

這是 GitHub Pages 用的靜態網頁版，使用原生 JavaScript，不需要伺服器或前端建置工具。介面以 PySide6 桌面版為規格，保留相同的工具列、分頁與主要操作流程。

目前包含：

- 桌面版相同的角色瀏覽器三欄配置
- 關鍵字、陣營、職業、品質、技能／能力與元素機制篩選
- 已擁有角色管理、匯入、匯出與只顯示已擁有角色
- 角色技能詳細資料、圖片顯示開關
- 桌面版相同的隊伍組成器：候選清單、九宮格、隊伍分析與多隊伍管理
- 敵隊分析、敵隊九宮格、威脅與反制需求
- 推薦隊伍與反制候選角色
- 台服官方更新公告清單
- 隊伍與擁有角色保存於瀏覽器 LocalStorage

## 本機預覽

因為瀏覽器的 `fetch()` 不允許直接用 `file://` 讀取 JSON，請在專案根目錄執行任一個靜態伺服器，例如：

```powershell
python -m http.server 8000
```

再開啟：

```text
http://localhost:8000/web/
```

## 與桌面版的差異

- 瀏覽器不能使用桌面的原生檔案選擇器，匯入／匯出改用瀏覽器下載與上傳。
- 瀏覽器不能執行桌面版的背景執行緒；官方公告每日檢查應由 GitHub Actions 執行，再讓網頁讀取更新後的 JSON。
- 桌面版的 Qt 對話框改為網頁彈出視窗，但操作內容保持一致。

## GitHub Pages

目前網頁資產位於 `web/`。後續可用 GitHub Actions 將 `web/` 發布到 GitHub Pages；官方公告自動更新則應由 GitHub Actions 產生 JSON，不能依賴瀏覽器直接爬取官方網站。
